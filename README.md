# TCMS Planner

**Part of the `tcms-*` family** — brand-side content skills for tech-product marketing teams.
*Not for neutral third-party industry research — that is `industry-deep-dive-pipeline`'s job.*

## What it does

Turns knowledge-base updates, competitor signals, and content calendars into structured topic briefs. Outputs 1-3 prioritized briefs per run.

It never writes article body text or auto-triggers downstream skills (that is `tcms-writer`'s job).

## Trigger phrases

选题, 本周内容, content plan, 选题建议, 内容规划

## Pipeline position

`tcms-planner` (brief) → `tcms-writer` (draft) → `tcms-compliance-reviewer` (review) → `tcms-adapter` (channels) → `tcms-performance-analyst` (monthly report)
